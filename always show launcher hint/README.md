# Always show launcher Hints on Homescreen

Show always the launcher hint on homescreen and you can adjust how many rows you can see. The Patch is based on "sailfishos-patch-homescreen-always-show-launcher" from @jakibaki and "sfos-patch-roundedrectangle-launcher-peek-rows" from @roundedrectangle  

Version 1.0.0 for Sailfish >= 5.2
